# Планер в Claude (MCP)

Облачный планер работает как MCP-сервер: Claude сам ходит в твой планер и в YouTube за данными и умеет записывать
в планер идеи, сценарии и дедлайны. Адрес: `https://youtube-planner.matvej-cher.workers.dev/mcp`.

## Подключение

### Claude на сайте, в приложении и на телефоне
1. [claude.ai](https://claude.ai) → **Настройки** → **Коннекторы** → **Добавить свой коннектор**.
2. Название — `YouTube-планер`, адрес — `https://youtube-planner.matvej-cher.workers.dev/mcp` → **Добавить**.
3. **Подключить** → откроется страница «Доступ к планеру» → введи пароль `PLANER_SECRET` → **Разрешить**.
   Если ты уже вошёл в облачный планер в этом браузере, пароль не спросит.

Коннектор, добавленный на сайте, появится и в приложениях Claude. В чате его можно включить или выключить
в меню инструментов.

### Claude Code
```
claude mcp add --transport http youtube-planer https://youtube-planner.matvej-cher.workers.dev/mcp
```
Дальше `/mcp` → войти через ту же страницу. Можно и без страницы — с заголовком
`--header "Authorization: Bearer <PLANER_SECRET>"`.

## Что умеет Claude

Читать:

| Инструмент | Что делает | Лимит YouTube |
|---|---|---|
| `channel_overview` | канал, монетизация, 28 дней аналитики, видео в работе, дедлайны | 1 |
| `list_my_videos` | твои видео: вышедшие со статистикой и «иксами», в работе, идеи | 0 (свежие цифры — 1) |
| `get_video` | видео целиком: все этапы со сценарием, статистика, удержание, трафик | 1 |
| `list_competitors`, `competitor_videos` | конкуренты и их ролики с «иксами» | 0 (обновить — ≈5) |
| `outliers` | «выстрелило» у всех конкурентов | 0 |
| `lookup_channel` | любой канал по @нику: подписчики и ролики с «иксами» | ≈5 |
| `search_youtube` | поиск по нише: просмотры к подписчикам | **100** |
| `trending` | «В тренде» по стране и категории (Gaming и т. д.) | 1 |
| `youtube_videos` | любые ролики по ссылкам | 1 |
| `video_comments` | комментарии к любому ролику | 1 на 100 |
| `title_insights` | слова-магниты в названиях ниши и разбор твоего названия | 0 |
| `channel_analytics` | закрытая аналитика канала: часы, досмотр, CTR, трафик, динамика, какие видео приводят зрителей, поисковые запросы, где смотрят, аудитория | 1 (нужен Google) |
| `video_analytics` | аналитика видео: удержание и где уходят зрители, трафик, CTR, какие видео приводят зрителей, поисковые запросы, где смотрят, аудитория | 1 (нужен Google) |
| `momentum` | что разгоняется прямо сейчас у тебя и конкурентов — к обычному темпу канала | 0 |
| `channel_history` | рост подписчиков и просмотров по дням (твой канал или конкурент) | 0 |
| `video_transcript` | дословная расшифровка любого публичного ролика с таймкодами (Gemini) | 1 (нужен Gemini) |
| `watch_video` | вопрос о самом видео: что на экране, хук, монтаж, темп (Gemini смотрит картинку и звук) | 1 (нужен Gemini) |
| `thumbnails` | картинки превью: свои, черновики из планера, конкуренты, любые ролики | до 1 |
| `best_time` | лучшее время публикации: когда смотрят твои зрители по часам и дням, оценка по странам, когда выходят конкуренты | 0 |
| `view_curve` | как обычно набирают просмотры (6 ч, сутки, неделя, месяц) и как идут свежие ролики против нормы | 0 |
| `packaging_changes` | кто сменил название или превью и что стало с просмотрами; превью до и после | 0 |
| `discover_channels` | новые конкуренты: рядом с чьими роликами YouTube рекомендует тебя, кого рекомендуют конкуренты | ≈15 (с поиском — +200) |
| `knowledge` | твоя база знаний (папка `knowledge/`) | 0 |

Записывать: `add_idea`, `update_video`, `update_stage` (сценарий и заметки; дописывает в конец, а заменить
написанное может только с явным подтверждением), `add_competitor`.

В день у YouTube API 10 000 единиц — обычной работы хватает с огромным запасом; дорогой только поиск.

## Глубокая аналитика
Во вкладке «Аналитика» (у канала — после «🔄 Обновить CTR и удержание», у видео — сама) и в ответах Claude:
- **Какие видео приводят зрителей** — ролики (свои и чужие), рядом с которыми YouTube рекомендовал твоё видео, и сколько просмотров пришло из-под каждого.
- **Поисковые запросы** — что вводили в поиске YouTube перед просмотром.
- **Где смотрят** — страница просмотра, главная, лента Shorts, плеер на других сайтах.
- **Аудитория** — страны, возраст, пол, устройства, подписчики против неподписанных (и сколько в среднем смотрят те и другие).

YouTube показывает по 25 первых строк и прячет возраст и страны, когда зрителей мало. Время, когда зрители онлайн,
API YouTube не отдаёт — его видно только в YouTube Studio.

## Транскрипты и «посмотреть видео» через Gemini (один раз, минуты 2)
Gemini от Google смотрит ролик по ссылке сам — наш сервер к YouTube не ходит, поэтому блокировок нет.
Бесплатно: до 8 часов видео YouTube в день (это 40–100 обычных роликов) и несколько запросов в минуту. Только публичные ролики.

1. [aistudio.google.com](https://aistudio.google.com) → **Get API key** → **Create API key** → выбери свой проект → скопируй ключ.
2. Cloudflare → воркер → **Settings → Variables and Secrets** → секрет `GEMINI_KEY` → Deploy.

Готовые расшифровки хранятся в облаке, повторный запрос мгновенный и бесплатный. Ответы на вопросы о видео — неделю.
Если Gemini думает дольше 50 секунд (длинный ролик), Claude получит «ещё смотрит» и через минуту-две заберёт готовое.
Расшифровка идёт частями по 5 минут параллельно (5 минут — примерно 6–10 секунд), за раз — до 30 минут. Модели перебираются сами:
для расшифровки — быстрые `gemini-3.5-flash-lite` и `gemini-3.1-flash-lite`, для вопросов о видео — `gemini-3.5-flash`; если модель перегружена,
берётся следующая. Свою модель можно задать секретом `GEMINI_MODEL`. Ключ добавляй как **Secret**, а не как Text.

## Постоянный доступ к YouTube Analytics (один раз, минут 5)
Без него Claude видит только аналитику, которую ты загрузил в планере кнопкой. С ним облако само обновляет
аналитику, CTR и часы до монетизации раз в сутки, а Claude смотрит удержание и трафик любого видео в любой момент.

1. [Google Cloud](https://console.cloud.google.com) → твой проект → **APIs & Services → Credentials** → **Web client 1**:
   - в **Authorized redirect URIs** добавь `https://youtube-planner.matvej-cher.workers.dev/google/callback`;
   - справа скопируй **Client ID** и **Client secret** → Save.
2. **OAuth consent screen** (или Google Auth Platform → Audience) → **Publish app** → статус **In production**.
   Без этого Google выдаёт ключ только на 7 дней. Проверка Google для личного приложения не нужна — при входе
   будет предупреждение «приложение не проверено», это нормально.
3. Cloudflare → воркер → **Settings → Variables and Secrets** → два секрета: `GOOGLE_CLIENT_ID` и `GOOGLE_CLIENT_SECRET`.
4. Облачный планер → **Аналитика** → **«Подключить Google навсегда»** → войди аккаунтом канала → разреши.
   В строке статуса появится «Google подключён к облаку: твой@gmail.com».

Ключ Google хранится в облаке зашифрованным. Если Google отзовёт доступ, планер, бот и Claude скажут «подключи заново».

## База знаний
Папка `knowledge/` в репозитории: темы в Markdown, формат — в `knowledge/README.md`. Список тем и правило
«когда заглядывать» Claude получает при подключении, а тексты — через инструмент `knowledge`. Файл `00-master.md` —
мастер-инструкция: её текст Claude получает целиком в каждом разговоре.

## Что облако делает само
- **Раз в сутки** — аналитика, часы до монетизации и CTR (если Google подключён). Утренний отчёт бота берёт свежие часы.
- **Раз в час** — просмотры всех твоих видео (1 единица лимита): из них — когда смотрят зрители и точные первые часы нового ролика.
  В часы без других задач — сверка превью у твоих роликов и роликов конкурентов (по 20 за раз, без лимита YouTube).
- **Раз в 6 часов** — снимок цифр: подписчики и просмотры твоего канала и конкурентов, просмотры свежих роликов.
  Отсюда «что разгоняется», история роста, нормы набора просмотров и смены названий; заодно в планере свежеют конкуренты (с новыми роликами)
  и копятся точки для графиков роста твоих видео — даже когда планер закрыт. Вместе с почасовыми замерами — около 65 единиц лимита YouTube в день из 10 000.

## Как это устроено
- Вход — OAuth 2.1 с PKCE, как требуют коннекторы Claude: клиент регистрируется сам, ты разрешаешь доступ паролем.
  Ключ доступа живёт сутки и продлевается сам; смена `PLANER_SECRET` отзывает все подключения.
- Правки из Claude и из открытого планера не затирают друг друга: у данных есть номер версии, а планер при
  конфликте сливает изменения (если одно и то же поле поменяли обе стороны, остаётся твоя правка).
  Открытый планер раз в 20 секунд проверяет, не записал ли Claude что-то новое, и тихо обновляется.
- Код: `cloud/mcp.js` (протокол), `cloud/oauth.js` (вход), `cloud/planer.js` (данные и расчёты), `cloud/tools.js` (инструменты),
  `cloud/google.js` и `cloud/analytics.js` (YouTube Analytics), `cloud/gemini.js` (транскрипты и просмотр видео), `cloud/timing.js` (время публикации), `cloud/curves.js` (набор просмотров), `cloud/packaging.js` (смены упаковки), `cloud/knowledge.js` и `knowledge/` (база знаний), `cloud/snapshots.js` (снимки), `cloud/jobs.js` (задачи по расписанию).
