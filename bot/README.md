# Облачный планер и Telegram-бот

Воркер Cloudflare из этого репозитория — это и сам планер (открывается по адресу воркера, вход по паролю),
и Telegram-бот.

Каждое утро присылает отчёт: подписчики, просмотры и новые комментарии за сутки, лучшее видео, дедлайны,
сколько осталось до монетизации и что «выстрелило» у конкурентов. Команды `/report`, `/deadlines`, `/money`.
Любой другой текст боту сохраняется как идея и появляется в планере в «Не начатых».

Всё работает в облаке Cloudflare бесплатно, поэтому отчёт приходит даже при выключенном компьютере.
Планер, когда открыт, отправляет туда короткую сводку: дедлайны, часы, id твоих роликов. Ключи и сценарии туда не попадают.

## Настройка (один раз, минут 10)

### 1. Создай бота в Телеграме
Напиши [@BotFather](https://t.me/BotFather) → `/newbot` → придумай имя → он пришлёт **токен** вида `123456:ABC…`.

### 2. Воркер в Cloudflare
Проще всего привязать воркер к этому репозиторию: **Workers & Pages** → **Create** → **Import a repository** →
`KowboyGG/youtube-planner`. Остальное Cloudflare возьмёт из `wrangler.jsonc` в корне репозитория: код бота,
хранилище KV (создастся само), расписание раз в час и адрес `*.workers.dev`. Новая версия бота выкатывается
сама после каждого изменения в ветке `main`.

<details><summary>Без привязки к GitHub (вручную)</summary>

1. **Create** → **Create Worker** → **Deploy** → **Edit code** → вставь содержимое `bot/worker.js` → **Deploy**.
2. **Storage & Databases** → **KV** → **Create** → `planer`; в воркере **Settings** → **Bindings** → **KV namespace**,
   имя переменной **`PLANER`**.
3. **Settings** → **Triggers** → **Cron Triggers** → `0 * * * *`.
</details>

### 3. Секреты
В воркере: **Settings** → **Variables and Secrets** → **Add**, тип **Secret**:

| Имя | Что вставить |
|---|---|
| `BOT_TOKEN` | токен от @BotFather |
| `YT_KEY` | тот же ключ YouTube Data API, что в планере («Настроить канал» → «Подключения») |
| `PLANER_SECRET` | любой длинный пароль — **им же ты входишь в облачный планер** |

### 4. Открой планер в облаке и перенеси данные
1. Открой адрес воркера (вида `https://youtube-planner.имя.workers.dev`) → введи пароль `PLANER_SECRET`.
   Браузер запомнит вход на полгода.
2. В **старом** планере на компьютере: «Настроить канал» → «Скачать копию .json» (картинки попадают внутрь файла).
3. В **облачном**: «Настроить канал» → «Загрузить из копии» → выбери этот файл.
4. В облачном планере заново впиши ключи в «Подключениях» (YouTube, ИИ): они хранятся в каждом браузере отдельно.
5. Для вкладки «Аналитика»: в Google Cloud → **Credentials** → **Web client 1** → **Authorized JavaScript origins**
   добавь адрес воркера (без `/` в конце) → Save.

### 5. Подключи бота
В облачном планере: «Настроить канал» → **Telegram-бот** → выбери час отчёта → **«Подключить»** → открой ссылку →
**Start** в Телеграме. Проверка — кнопка «Прислать отчёт сейчас».

## Что стоит знать
- Часы просмотра бот берёт из планера: они обновляются, когда ты жмёшь «Обновить» во вкладке «Аналитика».
  Подписчики, просмотры и комментарии бот берёт с YouTube сам.
- Приросты «за сутки» появляются со второго утреннего отчёта.
- Бот отвечает только чату, подключённому из планера. Остальным он пишет, что он личный.
- Бесплатных лимитов Cloudflare хватает с огромным запасом.
