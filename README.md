# youtube-planner

Локальный планер YouTube-канала в стиле самого YouTube: этапы производства видео, сценарии, дедлайны и календарь,
статистика и аналитика канала, конкуренты с «иксами» к медиане и ИИ-разбор (Claude, Gemini или ChatGPT).

Инструменты без ИИ: лаборатория превью (превью в ленте среди конкурентов, реальные размеры, карта внимания, выделяемость,
слова-магниты в названиях), лента «выстрелило» у конкурентов, радар ниши по ключевым словам, запросы зрителей из комментариев,
тренажёр чутья и путь к монетизации с прогнозом.


## Запуск

### В облаке (основной вариант)
Планер живёт в Cloudflare Workers (бесплатно) вместе с Telegram-ботом: открывается с любого устройства,
данные хранятся в базе Cloudflare D1, раз в день делается резервная копия (хранится 60 дней).
Вход по паролю — это значение секрета `PLANER_SECRET` воркера. Настройка — в [`bot/README.md`](bot/README.md).

### На компьютере (запасной вариант)
Нужен [Node.js](https://nodejs.org) 18 или новее.

- Windows: дважды щёлкнуть «Запустить планер.bat».
- Другие системы: `node planerserver.js` (порт можно сменить: `--port 5178`).

Планер откроется в браузере на `http://localhost:5178/`. Окно запускатора не закрывай, пока работаешь.
Данные локального планера и облачного — разные копии; переносить между ними — «Скачать копию» и «Загрузить из копии».

## Файлы

- `youtubeplaner.html` — сам планер (одна страница).
- `cloud/worker.js` — облачная версия: вход, данные, картинки, резервные копии (Cloudflare Workers + D1).
- `bot/worker.js` — Telegram-бот (часть облачного воркера).
- `wrangler.jsonc` — настройки воркера для Cloudflare.
- `planerserver.js` — локальный сервер: отдаёт страницу, хранит данные, делает резервные копии и пропускает
  запросы к ChatGPT и отчётам YouTube.
- `data/` — твои данные (`planer.json`, `competitors.json`, картинки). В git не попадает.
- `backups/` — ежедневные резервные копии. В git не попадает.

Ключи API хранятся только в браузере, в папку `data` они не пишутся.
